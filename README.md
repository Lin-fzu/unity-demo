# Unity Demo

个人 Unity 练习项目合集，使用 Unity 引擎开发。

## 项目列表

| 项目 | 说明 | 技术要点 |
|---|---|---|
| [PlaneDemo](./PlaneDemo) | 飞机射击类 Demo | Unity 物体控制、资源导入、UI 适配（Canvas Scaler）、PlayerPrefs 数据持久化、C# 事件/反射/泛型 |
| [Tank Game](./Tank%20Game) | 坦克对战 Demo | Unity 基础玩法、坦克控制、场景搭建 |

## 环境

- Unity 2022+
- C#

## 目录结构约定

每个项目为标准 Unity 工程结构，`.gitignore` 已排除 `Library/`、`Temp/`、`Logs/`、`obj/`、`UserSettings/` 等缓存与生成目录，clone 后用 Unity Hub 打开对应目录即可。

> 注意：美术资源包（如 PlaneDemo 中的 MagicArsenal 特效包）版权归原作者所有，请勿在仓库外二次分发。
